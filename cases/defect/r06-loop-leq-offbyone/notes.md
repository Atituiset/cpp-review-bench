# r06-loop-leq-offbyone 用例说明（三段式）

## 1. 真实仓形态
填充数组用 `for (i=0; i<=N; i++)` 而非 `i<N`，多写一字节——经典 <= 边界 off-by-one。

## 2. 真缺陷在哪
- **真缺陷**：`r06_fill` 的 `i <= R06_N` 比容量多一，`arr[R06_N]` 越界写（cwe-787）。
- **安全点**：`r06_fill_ok` 的 `i < R06_N` 正确，安全。

## 3. 各工具误判方式
- CSA / CppCheck / clang-tidy：应能查到 <= 边界越界（强项），基线对照。
- cooddy：符号执行识别多一字节——对照。
