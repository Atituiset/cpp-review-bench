# r07-alloc-size-wrap 用例说明（三段式）

## 1. 真实仓形态
`malloc(n * size)` 中 n/size 为窄类型时乘法先回绕，分配过小，后续按未回绕的全量
大小写入越界——经典整数回绕 + 堆溢出。

## 2. 真缺陷在哪
- **真缺陷**：`r07_alloc` 分配尺寸 `(size_t)(n * size)` 在 uint32 域先乘后转，
  回绕为小值；而清零循环上界 `(size_t)n * size` 在 size_t 域不回绕。如
  n=0x10001、size=0x10000：malloc 仅 65536 字节，循环却写入
  65537×65536=4295032832 字节，越界写 4294967296 字节（cwe-190+787）。
- **安全点**：`r07_alloc_ok` 的 `(size_t)n*(size_t)size` size_t 域乘法不回绕，
  分配与清零同一 total 且受 1MB 界，写入恒在界内。

## 3. 各工具误判方式
- CSA / CppCheck：对乘法回绕敏感度高（强项），基线对照。
- cooddy：符号执行应能精确识别回绕——对照。
