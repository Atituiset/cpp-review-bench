# r12-signed-unsigned-compare 用例说明（三段式）

## 1. 真实仓形态
边界检查只查上界、漏查下界是高频形态：`if (len < LIM)` 中 len 为有符号 int，
负值天然满足小于关系直接通过检查，随后 `buf[len]` 负索引越界读。真实仓里 len
常来自网络报文/协议字段，攻击者可控。

## 2. 真缺陷在哪
- **真缺陷**：`r12_use` 的 `len < LIM` 只查上界，len<0 时检查通过，`buf[len]`
  负索引越界读（cwe-125）。
- **安全点**：`r12_use_ok` 先 `len>=0 && len<LIM` 上下界齐备，负值被挡，安全。

## 3. 各工具误判方式
- CSA / CppCheck / clang-tidy：应能查到负索引越界读（数组边界分析强项），基线对照。
- cooddy：符号执行识别 len 可取负值——对照。
