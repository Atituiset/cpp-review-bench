## 3. KLEE 根因修复记录（本轮最大工程变更）

CI 首跑 KLEE 11 例全零 findings、每例 <1s，诊断为两层静默失败（镜像本身无问题）：

1. `_common.py normalize_file` 分支顺序 bug：KLEE 上报相对仓根路径
   `cases/defect/<cid>/src/x.c`，被 case_dir 相对化分支原样返回，永远到不了
   `cases/<track>/<cid>/` 截断分支 → anchor 合成失败 → finding 静默省略。
2. v3.x `.err` 多行格式（`Error:`/`File:`/`Line:` 分行）+ memcpy 走 freestanding
   runtime 时错误头部落内部位置——adapter 未解析 `Stack:` 帧回捞用户点位。

修复后：解析 v3.x 多行格式 + Stack 帧（同时产出 function 字段，twin 可区分）；
scenario 归一 `cwe-787+cwe-125` 并集（KLEE 不区分读写，eval 家族相交匹配）；
runner 增加「未真正执行/全 skip/有 err 无 findings」三类硬失败。
另修两个 harness：r01 布局与 B3 重写后的 src 不一致（win 64 项）、r09 符号化
malloc size 触达不到 double-free 路径（改具体值 70000）。
